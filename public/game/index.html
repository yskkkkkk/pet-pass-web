게임 방법

  1. 모두에게 같은 질문과 두 개의 선택지가 주어져요.
  2. 휴대폰으로 A 또는 B를 골라요. 결과 공개 전까지는 바꿀 수 있어요.
  3. 더 적은 사람이 고른 쪽만 생존, 다수파는 탈락해요. 투표하지 않으면 탈락!
  4. 동점이거나 모두 같은 선택이면 투표한 사람은 전원 생존해요.
  5. 생존자가 2명 이하가 되면 게임 종료, 남은 사람이 우승이에요.
