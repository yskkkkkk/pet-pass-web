# 미니게임 진행 순서

> 규칙과 설계는 `docs/minigame_plan.md`, 구조는 `docs/minigame_structure.md`.
> 단계 하나 = PR 하나. 끝난 항목은 `[x]`로 바꾸고 PR 번호를 적는다.

## 순서를 정한 이유

복잡도가 낮은 것부터 하나씩 새 능력을 더해 가도록 했다. 앞 단계에서 만든 공통 기반을 다음 게임이 그대로 쓴다.

| 단계 | 게임 | 새로 필요한 능력 |
|---|---|---|
| 0 | 공통 기반 | 게임 종류 저장, 점수제, 공통 대기실·순위표 |
| 1 | 블라인드 경매 | 숫자 입력, 사람별 자원(칩) |
| 2 | 빨강 / 파랑 | 진행자 설정(변형 규칙) |
| 3 | 가장 작은 유일한 숫자 | 판 형태 공개 연출 |
| 4 | 인디언 숫자 | 사람마다 다르게 보이는 비밀 정보 |
| 5 | 라이어 다이스 | 차례 진행(턴제) |

## 진행 상황

### 0단계 — 공통 기반
- [ ] SQL 작성·실행: `game_rooms.game / settings / state`, `game_players.data`, `game_moves` 테이블
- [ ] 방 만들 때 게임 종류 저장 (`DEFAULT_GAME` 제한 해제)
- [ ] 공통 대기실·참가 화면을 `public/game/shared/`로 분리하고 소수결을 옮김
- [ ] 공통 라운드 도구(제출, 조건부 마감), 점수판, 순위표, 카운트다운·순차 공개 도구
- [ ] 진행자 설정(라운드 수 등)을 대기실에서 바꾸기
- [ ] 규칙 단위 테스트 틀(`node --test`)과 Playwright 시나리오 틀
- **완료 기준**: 소수결이 새 공통 기반 위에서 기존과 똑같이 동작하고, 기존 테스트가 모두 통과

### 1단계 — 블라인드 경매
- [ ] 규칙 엔진 + 단위 테스트 (최고액 동점, 미제출 0, 칩 0, 최종 동점 처리)
- [ ] 진행 화면: 라운드 점수, 입찰 현황, 작은 금액부터 순차 공개, 순위표·남은 칩
- [ ] 참가 화면: 남은 칩, 입찰 입력(+1/+5/+10/올인), 내 순위
- [ ] Playwright: 2명, 6명, 응답 지연 시나리오
- **완료 기준**: 2명과 6명으로 10라운드 끝까지 진행되고 최종 순위가 맞음

### 2단계 — 빨강 / 파랑
- [ ] 규칙 엔진 + 단위 테스트 (과반 경계: 짝수·홀수 인원, 미제출 포함 분모)
- [ ] 무임승차 변형을 진행자 설정으로 제공
- [ ] 진행 화면: 과반선 게이지 연출 / 참가 화면: 빨강·파랑 버튼
- [ ] Playwright: 3명, 10명
- **완료 기준**: 기본 규칙과 변형 규칙 모두 점수 계산이 맞음

### 3단계 — 가장 작은 유일한 숫자
- [ ] 규칙 엔진 + 단위 테스트 (전부 겹침, 승자 점수 = 고른 숫자)
- [ ] 진행 화면: 1~10 숫자판 공개 연출 / 참가 화면: 1~10 버튼
- [ ] Playwright: 3명, 15명
- **완료 기준**: 3명과 15명 모두 판정·점수가 맞음

### 4단계 — 인디언 숫자
- [ ] 비밀 정보 응답 설계: 본인 숫자는 응답에 절대 포함하지 않음 (보안 테스트 포함)
- [ ] 규칙 엔진 + 단위 테스트 (판 이월, 칩 부족, 탈락)
- [ ] 진행 화면: 판의 칩, 결정 현황, 순차 공개(포기자 숫자 마지막) / 참가 화면: 남의 숫자, 가려진 내 카드, 승부·포기
- [ ] Playwright: 2명, 8명. 참가자 응답에 본인 숫자가 없는지 검사
- **완료 기준**: 어떤 응답에도 본인 숫자가 공개 전까지 나오지 않음

### 5단계 — 라이어 다이스
- [ ] 차례 진행 도구: 현재 차례, 다음 차례, 진행자 차례 넘기기
- [ ] 규칙 엔진 + 단위 테스트 (부르기 크기 비교, 판정, 탈락, 새 판 시작 순서)
- [ ] 진행 화면: 차례·부른 기록·남은 주사위, 주사위 펼치기 연출 / 참가 화면: 내 주사위, 부르기, 의심(내 차례만)
- [ ] Playwright: 2명, 6명, 자리 비운 사람 차례 넘기기
- **완료 기준**: 마지막 1명이 남을 때까지 진행되고, 비밀 주사위가 본인 외에 노출되지 않음
