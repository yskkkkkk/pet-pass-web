# 008 — 데이터 없는 XML 응답을 동물 인증 성공으로 오판

**우선순위:** P1

**분류:** 구현 결함 / 동물 조회·펫 패스

**상태:** 미해결

## 근거

- `api/get-pet-data.js:96-109`: XML 파서는 태그가 없어도 값이 모두 `null`인 키 6개의 `body.item`을 만든다.
- `api/get-pet-data.js:115-134`: 키 수가 5보다 크면 실제 값 유무와 무관하게 `hasData`로 판단하고 `success: true`를 반환한다.
- `api/auth-pet.js`와 `server.js`의 `/api/auth-pet`에도 별도의 데이터 존재 판정 및 성공 시 테스트 데이터 대체 경로가 있다. 판정 계약을 함께 확인해야 한다.

## 재현과 영향

정부 API 키가 설정된 상태에서 외부 응답을 다음으로 모의한다.

```xml
<?xml version="1.0"?>
<response>
  <header><resultCode>00</resultCode></header>
  <body><totalCount>0</totalCount></body>
</response>
```

조회 API에 형식상 유효한 입력을 보내면 `dogNm` 등은 `null`인데 `success: true`와 “인증에 성공하였습니다”가 반환된다. 누락된 동물등록번호와 생년월일은 입력값으로 보충된다. 외부 API 호출 없이 Axios 응답을 모의하여 이 결과를 확인했다.

통신 성공 코드와 실제 등록정보 존재는 다르다. 현재 경로는 데이터 없음 안내를 건너뛰고 빈 정보로 펫 패스를 만들 수 있다.

## 수정 방향

XML/JSON을 같은 내부 형식으로 정규화하고 실제 항목 존재·필수 값으로 등록정보 유무를 검증한다. 키 개수만으로 인증 성공을 판단하지 않는다. 조회 0건·빈 태그·예상하지 못한 응답은 인증 성공이나 테스트 동물 데이터로 대체하지 않고 명시적으로 구별한다. 명시적인 개발용 모의 응답과 실 API 성공 판정을 혼동하지 않도록 한다.

## 완료 기준

- [ ] 결과 코드 `00`이어도 실제 항목이 없으면 `success: true`를 반환하지 않는다.
- [ ] 빈 XML 태그와 값이 모두 비어 있는 JSON 항목을 동일하게 처리한다.
- [ ] 정상 XML/JSON의 실제 등록정보는 계속 표시된다.
- [ ] `/api/get-pet-data`, Vercel `/api/auth-pet`, 로컬 `/api/auth-pet`의 존재 판정이 일치한다.
- [ ] 외부 API를 모의한 정상·0건·빈 값·오류 응답 회귀 테스트를 추가한다.
